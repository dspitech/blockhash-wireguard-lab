            Sauvegardes de wg0.conf

              Rotation des clés serveur

              Génère une nouvelle paire de clés pour le serveur et régénère automatiquement le .conf de chaque client existant (leurs propres clés ne changent pas). Une sauvegarde de sécurité est créée avant toute modification. Tous les clients devront réimporter leur configuration.

              Maintenance du tunnel

              Redémarre le service wg-quick@wg0. Les clients se reconnectent automatiquement (WireGuard est sans état), avec une brève coupure.

              Export d'audit

              Zip contenant tous les .conf clients (clés privées incluses), wg0.conf et un manifeste CSV non sensible.

              Multi-serveurs

              Supervision agrégée d'autres instances BLOCKHash — voir README 7.8.5. La gestion détaillée des clients d'un serveur distant se fait depuis son propre dashboard.
